\# Grid Square Worked



Maidenhead grid square worked tracker by \*\*D\&C Ham Adventure (M7ANI)\*\*.



Tracks which grid squares you have worked on eight regional maps (UK, Europe, North America, South America, Africa, Asia, Australia, Antarctica). Upload an ADIF log file and every grid you have contacted is highlighted.



\## Features

\- 8 regional map tabs

\- ADIF log import — auto-saved to `gridlog.json`

\- Log tab with Band/Mode filters and distance calculations

\- Live Propagation data (hamqsl.com / N0NBH)

\- Live NOAA SWPC space weather with alerts

\- Live DX Cluster spots with filters

\- Light and Dark theme

\- Fully customisable colours



\## How to run

1\. Download `GridSquareWorked.ps1`

2\. Right-click → \*\*Run with PowerShell\*\*

3\. Open \*\*Settings\*\* and enter your callsign, name and grid square.

4\. Click \*\*Upload ADIF\*\* to populate the maps.



\## Disclaimer

This is a hobby project made for fun. Grid square data is not verified and some squares may be off. Please do not rely on it for awards or contests.
